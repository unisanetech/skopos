# Semantic Drift Guard Pack

## Purpose

Use this pack when a project can pass builds and ordinary documentation checks while
still teaching a retired architecture path, preset, command, or product rule as
current truth.

The pack supplies templates, not project meaning. A human or coding agent must ground
each retired pattern and each allowed context in accepted Project Memory.

## Adoption

1. Copy the templates into `tools/skopos/` inside the adopted project.
2. Replace every example pattern with reviewed project truth.
3. Add positive violations and allowed negative, historical, and temporary examples.
4. Register the script as a project Action.
5. Bind that Action through a Guard scoped only to the relevant documents.
6. Run the project Action and retain its source-bound Evidence.

Skopos core must never contain the consuming project's retired phrases.
