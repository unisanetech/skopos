Events / Quickstart

Send your first event

Publish a test event, inspect the response, and verify delivery in three steps.

  1. Install the SDK

    Add the Relay package to your application.

  2. Send an event

    Use a stable event name and include only the properties your consumer needs.

  3. Verify delivery

    A successful response confirms acceptance, not downstream processing.

import { Relay } from '@relay/sdk';

await relay.send('invoice.created', {
  invoiceId: 'inv_2048'
});
