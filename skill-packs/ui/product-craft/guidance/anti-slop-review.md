# Anti-Slop Visual Review

Review rendered evidence, not source code alone.

Reject:

1. generic dashboard styling that does not express the bound brand
2. arbitrary cards, gradients, shadows, icons, pills, or oversized headings
3. inconsistent spacing, radii, type roles, control heights, or alignment
4. repeated headings, descriptions, labels, and empty-state explanations
5. customer-facing technical identifiers or implementation language
6. missing loading, error, empty, permission, disabled, or recovery states
7. clipped, overflowing, hidden, or de-prioritized critical content
8. a broad client-rendered tree created for one local interaction
9. visual polish without keyboard, accessibility, responsive, and focused-test evidence

The rubric produces review evidence. It does not declare the task complete.
