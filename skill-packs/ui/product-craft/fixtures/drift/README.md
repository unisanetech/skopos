# Product UI Craft Drift Fixture

The fixture represents a superficially polished screen with raw visual values, generic
card-heavy composition, repeated copy, one broad client boundary, desktop-only layout,
arbitrary type and spacing, competing borders and surfaces, broken alignment, clipped
bounded content, ambiguous interaction state, and no error or recovery evidence. The
skill should be recommended and the applicable project guards must remain separate
closure evidence.

Its interface also uses vague labels such as `Submit` and `Manage`, repeats headings,
exposes status codes and permission scopes, interrupts routine work with confirmation
dialogs, says `Are you sure?` without naming the consequence, and leaves empty and
error states without a useful next action.
It creates `AdvancedAsidebarWithMotion` beside an equivalent sidebar, copies markup
instead of using a shared variant, prefixes local components with temporary feature
language, and repeats the same page noun in the shell title, eyebrow, heading,
description, tabs, and supporting panels.
